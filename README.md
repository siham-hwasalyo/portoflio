##  À propos du projet

Ce projet est mon portfolio personnel développé dans le cadre de ma formation en Développement Digital. Il présente mon profil, mes compétences techniques ainsi que mes projets réalisé

##  Fonctionnalités

* Design moderne et épuré
* Site entièrement responsive (mobile & desktop)
* Section “À propos de moi”
* Présentation des projets avec descriptions et liens
* Section des compétences techniques
* Possibilité de télécharger le CV

## Technologies utilisées

* HTML5
* CSS3
* JavaScript (interactions de base)
* Tabler Icons

##  Projets présentés

* **Système POS** : application de gestion de caisse avec JavaScript et manipulation du DOM
* **Site e-commerce** : interface responsive développée avec HTML, CSS et Bootstrap
* **Gestion des stagiaires** : application desktop en Python (Tkinter) avec export des données

## Objectif

Ce portfolio a été créé afin de présenter mes compétences, valoriser mes projets et faciliter ma recherche de stage en développement web et digital.
