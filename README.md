## ✨ Aperçu

Design sombre et épuré (noir profond `#0d0d14` + accent doré `#c9a96e`), typographie éditoriale
(*Cormorant Garamond* + *DM Sans*), et une navigation fluide en une seule page (*single page*) organisée
en sections :

- **Hero** — présentation, liens GitHub / LinkedIn, téléchargement du CV
- **About Me** — présentation personnelle
- **Experience** — timeline chronologique de mes expériences professionnelles
- **Projects** — mes projets réalisés en stage et en formation, avec captures d'écran et liens GitHub
- **Skills** — compétences techniques (front-end, back-end, data, outils) et savoir-être
- **Resume** — téléchargement du CV au format Word

## 🧩 Fonctionnalités

- 🎯 Timeline d'expérience avec repères visuels chronologiques
- 🖼️ Visionneuse (modale) pour consulter les captures d'écran et l'attestation de stage en grand format,
  sans déformation d'image
- 📄 Ouverture directe du rapport de stage (PDF) et du CV (Word) dans un nouvel onglet
- 🎚️ Barre de progression de lecture en haut de page
- 🧭 Navigation collante (*sticky*) avec effet de flou au scroll, lien actif mis en évidence, et menu
  hamburger sur mobile
- 🌀 Animations d'apparition au scroll (*scroll reveal*)
- 📱 Design 100% responsive (mobile / tablette / desktop)

## 🚀 Lancer le projet en local

Aucune installation ni dépendance n'est nécessaire, c'est un site statique.

```bash
git clone https://github.com/siham-hwasalyo/portfolio.git
cd portfolio
```

Puis ouvre simplement `index.html` dans ton navigateur, ou lance-le avec un serveur local
(ex : l'extension **Live Server** de VS Code) pour un rendu optimal.

## 🌐 Déployer sur GitHub Pages

1. Pousse ce dossier sur un repository GitHub (ex : `portfolio`)
2. Va dans **Settings → Pages**
3. Choisis la branche `main` et le dossier `/ (root)`
4. Ton portfolio sera accessible à l'adresse `https://siham-hwasalyo.github.io/portfolio/`
